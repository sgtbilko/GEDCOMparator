# GEDCOMparator

This is a tool created using Claude Code by Mark Tiffany.



## Usage

Open the HTML file in a browser.  Select two different GEDCOM files, e.g. exported from Ancestry and WikiTree.  Then identify the same root person in each file and what set of people to compare.



Matches are then shown with options to hide/show details as required based on your reason for comparing.

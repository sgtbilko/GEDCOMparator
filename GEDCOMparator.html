GEDCOM Tree Comparator

Upload two GEDCOM files that share a common root person. The tool walks direct ancestors from that root, optionally including each ancestor's spouse, each ancestor's siblings (and siblings' spouses), and each ancestor's own children for a chosen number of generations, and reports who's missing from either file and where their recorded details (birth, death, marriage) disagree.
